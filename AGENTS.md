# Agent instructions

This repository now hosts the Score capability agent (`agents/capability-agent`). Terraform modules live in `score-tf-modules` (`terraform-aws/`, `eks/`) and Score provisioners, state and generated manifests in `score-gp-aws-rds` (`rds/`, `eks/`). Treat module inputs and outputs as an API: preserve names and types. Never run `score-k8s init` in an existing Score project folder or edit its `state.yaml` by hand: its GUIDs name live Terraform CRs. Do not deploy, apply infrastructure, or commit credentials without explicit user instruction. Pin Flux sources to reviewed Git tags.
